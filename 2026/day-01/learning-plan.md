# 90 Days DevOps Learning Plan

## Current Level
I am a final year Computer Science Engineering student currently exploring DevOps and Cloud Engineering. I have basic programming knowledge and hands-on experience with projects, and I want to build strong infrastructure and deployment skills.

## My Understanding of DevOps & Cloud
I understand DevOps as a combination of development, operations, automation, and continuous delivery practices used to build and deploy applications efficiently. Cloud Engineering helps organizations manage scalable infrastructure and services using platforms like AWS.

## Why I Am Learning DevOps
I am learning DevOps to become industry-ready and gain practical skills in Linux, Cloud, CI/CD, Docker, Kubernetes, and automation. My goal is to build real-world deployment experience and improve my problem-solving abilities.

## My 90-Day Goals
1. Build strong Linux, networking, and Git fundamentals
2. Learn Docker, CI/CD pipelines, and AWS basics
3. Deploy applications using Kubernetes and complete an end-to-end DevOps project

## Core Skills I Want to Build
- Linux troubleshooting and system administration
- CI/CD pipeline implementation
- Containerization and Kubernetes basics

## Weekly Time Commitment
- Weekdays: 2 hours daily
- Weekends: 4–5 hours daily

## Consistency Plan
I will stay consistent by practicing every day, maintaining handwritten notes, pushing my work to GitHub regularly, and sharing my learning journey publicly on LinkedIn.
